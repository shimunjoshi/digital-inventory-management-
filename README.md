# SmartStock – Digital Inventory Management System

SmartStock is a browser-based inventory management prototype designed for small shops. It helps shop owners maintain product records, monitor stock levels and record sales from a simple dashboard.

## Features
- Dashboard with product count, units in stock, inventory value and low-stock alerts.
- Add, edit and delete products.
- Search products and filter by category.
- Low-stock and out-of-stock indicators.
- Record sales and automatically deduct sold quantities from stock.
- Sales history and revenue summary.
- Data persistence using browser LocalStorage.
- Responsive layout for desktop and mobile screens.

## Technology
- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Start using the sample inventory, or add your own products.

No server or package installation is required.

## Deploy with GitHub Pages
1. Push the project files to the `main` branch of a public GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Open the published URL shown by GitHub Pages.

## Important prototype note
This prototype stores data in the browser's LocalStorage. Data is specific to the browser/device and is not synchronized between users or devices. It is intended for academic demonstration and is not a production multi-user inventory platform.
